# AEOLIA 紹介映像

社内勉強会で作品の雰囲気を約26秒で紹介する映像です。

## 構成

1. 作品名
2. 浮島の街
3. 郊外
4. 遊戯室
5. 公開案内

`capture-cinematic.mjs` が専用カメラの収録、`render-cinematic.sh` が映像とBGMの合成処理です。
ゲーム画面は1280×720で収録し、生成フレームはGitの管理対象から外しています。ナレーションは使用せず、短い画面内テキストと環境音楽だけで構成しています。

旧版の台本と合成処理は、比較用に `narration.txt` と `render-intro.sh` へ残しています。
