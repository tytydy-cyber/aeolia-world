# 雲海紀行

プレイ中のページは更新後に再読み込みしてください。

## 起動

このフォルダで `python3 -m http.server 8765 --bind 127.0.0.1` を実行し、ブラウザで `http://localhost:8765/` を開きます。Three.jsとフォントの初回取得にはインターネット接続が必要です。

## 操作

- 十字キー：移動（WASDも使用可能）
- ドラッグ：左右・上下を見渡す。左・右ボタンのどちらでも操作でき、通常のマウス移動では回転しません。
- Q・E：視点を左右へ旋回
- C：最後に移動した方向へ視点を滑らかに戻す
- F：歩行／飛行の切り替え
- Space／Shift：飛行中の上昇／下降
- Ctrl：移動中の加速
- 左下の「速さ」：速度を0.7〜1.6倍に調整
- 左下の「消音」「音量」：音のオン／オフと音量調整
- 左下の「移動エフェクト」：砂ぼこり・風の軌跡・着地演出のオン／オフ
- Esc：設定のキーボード操作を終了して散策に戻る。マウスで設定を操作した場合は自動で散策へ戻ります。

標準速度は歩行10、飛行28ワールド単位／秒。加速時は16／44。旧版の標準速度は5.8／17です。

## Blender素材

- `assets/aeolia-house.blend`：編集用の建物原本
- `assets/aeolia-house.glb`：ゲームに読み込むモデル。9棟で共有します。
- `assets/house-preview.png`：Blenderの照明でレンダリングした素材確認画像。ゲーム画面とは照明が異なります。

建物の読み込みに失敗すると簡易モデルを表示して移動を継続できます。再読み込みで再試行します。

建物は外観モデルです。内部への入場は未対応です。

## 主人公

単純な円錐と球の構成をやめ、曲面の外套、肩布、顔、髪、帽子、ベルト、鞄、袖、手、立体的な靴で構成しています。歩行と飛行の既存モーションはそのまま各部へ適用されます。

## 音と街の小物

「世界に入る」を押すと風の環境音が始まります。歩くと足音が鳴り、橋の上では音色が変わります。飛行速度に合わせて風切り音が強まり、場所を発見すると鐘が鳴ります。別のタブやウィンドウに移ると音を一時停止します。音はブラウザ内で合成するため、音声ファイルのダウンロードは不要です。

すべての音はリミッターを通し、環境音・足音・鐘が重なった場合のクリッピングを抑えています。

植木鉢34個、木箱20個、ベンチ12脚、屋台1台を追加しました。部品を含めて7つの描画グループ、計22,104三角形です。追加の動的光源や影の描画は設けていません。各オブジェクトには衝突判定があります。

移動・衝突、GLB読込と配置、音の開始／消音／停止／再開のロジックを自動テストしています。実ブラウザでFPSとゲーム画面も確認しています。

2026-09-16の修正で、塔・風車の衝突、橋の下の飛行、設定後の操作復帰、低FPS時の移動速度を修正しました。5〜120fps相当の更新で移動距離が一致することを確認しています（実GPUのFPS測定ではありません）。検査結果と残タスクは `QA-2026-09-16.md` を参照してください。

実ブラウザ確認で開始位置のカメラ遮蔽が見つかったため、中央市場を見渡せる地点へ開始位置を変更しました。実WebGLでテクスチャ・影・建物・小物・HUDの表示を確認済みです。

ドラッグの上下可動域を拡張しました。空や足元を見渡せますが、パノラマの上下端や地形裏面が見えない範囲に制限しています。カメラは移動方向へ常時吸着せず、Cを押したときだけ最後の進行方向へ約0.3秒で戻ります。

中央島は複数周期の起伏を重ねた非対称な輪郭に変更し、見た目と移動判定を同じ形状に揃えました。木は幹・枝・小さな樹冠の集合へ作り直し、34本分を5つのインスタンス描画にまとめています。

橋の手すりは、各区間の前後の橋面高から傾斜を求め、橋の勾配へ沿うよう修正しました。

実GPU計測では飛行中に47fpsまで低下したため、描画解像度の上限と影マップを調整しました。同じブラウザ・操作で飛行中60fps、p95 17.8msに改善しています。URLに `?debug=1` を付けると右上に計測値を表示できます。

## テクスチャと移動エフェクト

`assets/textures/` に漆喰・石・瓦・草地・木・岩壁のカラー画像と凹凸画像を保存しています。各512×512ピクセルで繰り返し利用し、Blender製建物にもゲーム側で適用します。背景は2048×1024ピクセルの雲と山並みのパノラマです。

歩くと足元に砂ぼこりが出ます。飛行中は左右に風の軌跡が残り、停止すると消えます。着地時にも小さな砂ぼこりを出します。エフェクトは最大128要素・描画2回に制限しています。OSで動きを減らす設定を使用している場合、初期状態では無効です。

`assets/aeolia-house-textured.blend` はテクスチャを内包した編集用原本、`assets/house-textured-preview.png` はBlenderによる素材確認用レンダーです。ゲーム内とは照明や質感の計算が異なります。

## 多層遠景

生成した2D画像を、3D街並みの外側に二段階で配置しています。

- `assets/textures/sky-cities.jpg`：浮遊都市・雲海・環状遺跡の遠景パノラマ
- `assets/textures/distant-ruins.png`：透過背景の中距離遺跡。左右を別々に切り出し、2枚のレイヤーとして配置

中距離レイヤーはごくゆっくり上下し、透明度もわずかに変化します。追加の3Dモデルや影は使わず、描画追加は2回です。実ブラウザの飛行時測定では60.0fps、p95 17.6msを維持しました。
